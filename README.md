Python Learning Repository

list.py: Working with lists in Python.
tuple.py: Understanding and using tuples.
dictionary.py: Exploring dictionaries for data storage.
number_operators.py: Performing calculations with operators.
comment.py: Learning how to use comments in code.
and more...
Functions:

functions.py: Defining and using functions for reusability.
exponent_function.py: Creating a function for calculating exponents.
perimeter.py: Writing a function to calculate the perimeter of shapes.

while_loop.py: Implementing while loops for repeated actions.

writing_to_file.py: Writing data to text files.

multiple_choice_question.py: Implementing a multiple choice quiz.
(and potentially more!)
